    遊び方
    
      
    店と株で総資産を伸ばし、目標に達した状態で銀行に止まる（または通過する）と勝ちです。
    

      
    
        
    はじめに
    
        
      
          
    • 自分の番でサイコロを振り、マスを進みます（通常は1〜6。エリアが11以上のマップは1〜10）。分岐では進む方向を選びます。
      • 
          
    • マップは中央クロス／貝がら港／がけした島／アーチ／弾丸／田改／暮違某為町／空島地帯／強欲鉱山から選べます。マップごとにダイスの面数が違います（例: アーチ・強欲鉱山1〜7、田改1〜8）。アーチ・田改の休みマスに止まると、自分の店が1ターン休店します（買い物料0）。空島はランダム転移・門・薬品（全員で伏せカード選択）、強欲鉱山は階層移動・鉱石マスがあります。
      • 
          
    • サイコロは常時表示の操作欄から振れます。スマホでは手番／所持／記録はボタンで開く詳細シートです（PCは右パネル）。
      • 
          
    • 盤上のコマには進行方向の矢印が付き、手番プレイヤーの次マスも点線で示されます。サイコロ後は分岐を踏まえた最終停止マスが縁取りハイライトされ、そのマスを直接クリックしても進めます。
      • 
        
    
      
    

      
    
        
    お店
    
        
      
          
    • 空き店に止まると購入。他人の店なら買い物料を払います。
      • 
          
    • 自分のターン（サイコロ前）に物件取引で他プレイヤー／CPUと店の交換を提案できます（複数対複数可）。差額はデフォルトで精算され、変更も可能。相手は承認か拒否のみです。
      • 
          
    • 同じエリアの店が多いほど買い物料が上がります。エリア独占で倍率最大＋店価合計の15%ボーナス（店価自体は増えません）。
      • 
          
    • 独占が崩れると株価が大きく下落し、残店の増資も削られます。
      • 
          
    • 自分の店に止まると、好きな自分の店へ増資できます。上限はエリア独占率で変わります（例: 1/4→0.5倍、半分→1倍、75%→3倍、独占→9倍）。
      • 
        
    
      
    

      
    
        
    株
    
        
      
          
    • 銀行・証券でエリア株を売買できます（1回の訪問で買えるのは1種類）。プレイヤーカードや所持表の株をクリックすると、盤面でそのエリアが光ります。
      • 
          
    • そのエリアで買い物料が発生すると、保有に応じてわけ前（銀行から）が入ります。
      • 
          
    • 自分のターン内で、エリアごとに10枚売るごとに株価が下がります。次の自分の番で累計はリセットされます。
      • 
          
    • まとめて買うと株価が上がることがあります（購入パネルに予想が表示されます）。
      • 
        
    
      
    

      
    
        
    マーク・スクラッチ・ワイルド
    
        
      
          
    • 四隅の ♠♥♦♣ は通過でマーク入手。ぴったり停止するとイベント表を1マス削れます。
      • 
          
    • スクラッチマスに止まっても同様に1マス削れます。表は全員共通で、開けた人の色で塗られます。
      • 
          
    • 同じ色が隣り合って縦・横・斜めに3つ以上そろうとボーナス（枚数×50G）。とびとびは無効です。
      • 
          
    • がけした島のワイルドマスは通過／停止でワイルドカード入手（最大4枚）。ぴったり止まるとスクラッチも1回。銀行到達時、レベルアップできる枚数がそろっているときだけ必要枚数を消費します（足りなければ消費しません）。
      • 
          
    • スクラッチ等でマーク／ワイルドマスへワープしたときも、そのマスの入手が入ります。
      • 
        
    
      
    

      
    
        
    銀行と勝利
    
        
      
          
    • マークをそろえて銀行に戻ると、昇進 → 株1種類 → 進む方向の順です。
      • 
          
    • 昇進賞金はレベルごとに全員同額（高いほど増えます）。
      • 
          
    • 総資産が目標以上なら、銀行に止まる／通過すると勝利。昇進賞金だけで初めて目標に達した場合は、いったん出てから再通過が必要です。
      • 
          
    • 誰かが目標に達するとBGMが変わります。終了後は順位・統計・アワードを表示／エクスポートできます。タイトルの試合結果から保存したJSONをあとから表示できます。
      • 
        
    
      
    

      
    
        
    イベント・ミニゲーム
    
        
      
          
    • スクラッチやチャンスには、店価操作・買収クーポン・強制売却・独占打開などがあります。
      • 
          
    • スクラッチでマークの妖精／大商人／貧乏神を呼べます（同種は同時に1体まで）。NPCは周回ごとに徘徊し、3〜7回行動したあと異界へ帰ります。
      • 
          
    • ラッキー中は、他者の買い物料の20%を銀行から受け取れます（次の自分の番まで）。
      • 
          
    • ミニゲームの報酬はレベルで緩やかに上乗せ（一発当たりは目標額の約8%まで）。サイコロ当て／コイン／ハイロー／競馬／ルーレットなど共通結果型は全員参加（選択がそろってから精算）。スロットや金庫破りなどは引いた人だけの個人挑戦です。
      • 
          
    • CPUには店舗王／株マニア／独占屋／勝負師の個性があります。
      • 
        
    
      
    

      
    
        
    オンライン
    
        
      
          
    • ホストが部屋を作りコードを共有。ゲストは同じコードで入室。バージョンが違うと入れません（タイトルに表示）。
      • 
          
    • 開始前に順番決めダイス（1〜100）で手番順を決めます（同点は同じ出目の人だけ振り直し）。出目がそろったら順位を表示し、ホストが開始を押すとゲームへ進みます。ロビーでプレイヤー色・初期資金（既定2200G）・目標資産を設定できます。
      • 
          
    • 切断しても同じ部屋コード・同じ名前で再接続できます。ホストは切断者をCPU化／キックできます。
      • 
          
    • 相手の操作待ちでは催促ボタンが使えます。部屋を作り直すときは先に部屋を解体します。
      • 
        
    
      
    

      
    
        
    画面の見方
    
        
      
          
    • 出来事は盤面中央に出ます。手番の人が「つづける」で進めます（5秒触らなければ自動で閉じます。NPC手番はNPCが進みます）。
      • 
          
    • 選択ダイアログは「隠す」で一時退避できます。分岐の行き先は盤の端に出ます。
      • 
          
    • 現金の出入りは画面中央とプレイヤー欄に表示。左上のフィードでもさかのぼれます。
      • 
          
    • スペースでサイコロ／出来事のつづける／選択スキップができます（クリックもそのまま使えます）。
      • 
          
    • 盤面右下の＋／−／全体、またはホイールで拡大縮小。拡大中はドラッグで移動できます。
      • 
        
    
      
    

      
    
        
      
    
    
    
  
    

  
  
    
    
    
      
    順番決めダイス
    
      
    1〜100の出目が大きいほど先手。同じ出目の人だけ振り直します。スペースでも振れます。
