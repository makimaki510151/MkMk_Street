# MkMk Street

いただきストリート風の **P2Pマルチプレイすごろく** です。GitHub Pages でそのまま公開できます。

> 参考にした Minecraft datapack（`itadaki_street`）はクラウド環境に含まれていなかったため、同系統の標準ルール（お店・エリア独占・増資・株・マーク昇進・銀行ゴール）をベースに 2D で再構築しています。

## 遊び方

1. **部屋を作る（ホスト）** → 表示された部屋コードを友達に共有
2. 友達は **部屋に入る（ゲスト）** で同じコードを入力
3. ホストが「ゲーム開始」でスタート（足りなければ CPU 追加可）
4. サイコロで進み、**分岐点でルートを選び**、お店・株で総資産を伸ばす
5. **総資産が目標に達した状態で銀行に止まる**と勝利

ローカル / CPU 対戦だけでも遊べます。

## ルール概要

| 要素 | 内容 |
| --- | --- |
| マップ | 銀行を中心にした十字＋外周ループ。交差点で進行方向を選択（本家風） |
| お店 | 空きなら購入。他人の店は買い物料。自分の店は増資可 |
| エリア | 同エリアの所有数で買い物料倍率（2軒1.25倍〜4軒5倍など） |
| 株 | 銀行・証券マスで売買。店の価格平均に連動。配当あり |
| マーク | ♠♥♦♣ を揃えて銀行に戻ると昇進ボーナス |
| 5倍買い | 他人の店に止まったとき、店価×5で強制買収できる場合あり |

## GitHub Pages

リポジトリの **Settings → Pages** で Branch を `main`（またはこのPRのブランチ）、Folder を `/ (root)` にしてください。

公開URL例: `https://makimaki510151.github.io/MkMk_Street/`

## 開発

静的ファイルのみです（ビルド不要）。ローカル確認:

```bash
python3 -m http.server 8080
```

テスト:

```bash
node --test tests/*.test.mjs
```

## 技術

- 纯フロントエンド（ES Modules）
- 描画: Canvas 2D
- 通信: [PeerJS](https://peerjs.com/)（WebRTC DataChannel、ホスト権威の状態同期）
