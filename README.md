# MkMk Street

お店・株・エリア独占で総資産を競う **P2Pマルチプレイすごろく** です。GitHub Pages でそのまま公開できます。

## 遊び方

1. **部屋を作る（ホスト）** → 表示された部屋コードを友達に共有
2. 友達は **部屋に入る（ゲスト）** で同じコードを入力
3. ホストが「ゲーム開始」でスタート（足りなければ CPU 追加可）
4. サイコロで進み、**分岐点でルートを選び**、お店・株で総資産を伸ばす
5. **総資産が目標に達した状態で銀行に止まる**と勝利
6. 終了時は **順位・資産内訳バー・スペシャルアワード** を表示

ローカル / CPU 対戦だけでも遊べます。

以下は通常プレイでも動作します（`?demo=` は確認用ショートカット）:
- 終了時の統計画面・アワード
- 手番／所持／記録どのタブでもサイコロ
- イベント発生時のフラッシュ（手番／NPCが確認するまで進行停止）
- 現金増減の中央表示（買い物料・購入・わけ前など）
- エリア買い物料発生時の株わけ前

確認用デモURL:
- `?demo=results` … 終了統計画面
- `?demo=event-fx` … 所持タブ＋イベントフラッシュ
- `?demo=money-fx` / `money-loss` / `money-invest` … 現金表示
- `?demo=stock-div` … 株わけ前

## ルール概要

ゲーム内の「遊び方」画面と同じく、要点だけです。

| 要素 | 内容 |
| --- | --- |
| 勝利 | 総資産が目標以上の状態で銀行に止まる／通過する（昇進賞金だけで初到達なら再通過が必要） |
| お店 | 空きなら購入。他人の店は買い物料。同エリア所有で倍率アップ。独占で最大倍率＋店価合計15%ボーナス |
| 増資 | 自分の店に止まると好きな自分の店へ増資可。上限はエリア独占率で変化 |
| 株 | 銀行・証券で売買。買い物料発生時にわけ前。自分のターン内で10枚売るごとに株価下落（次の自分の番でリセット） |
| マーク | 四隅 ♠♥♦♣ は通過で入手。ぴったり停止／スクラッチマスでイベント表を1マス削る |
| ワイルド | がけした島。通過／停止でカード入手（最大4）。停止時はスクラッチも。銀行でレベルアップできるときだけ必要枚数を消費 |
| スクラッチ | 全員共通の表。隣り合う同色3つ以上でボーナス。ワープ先がマーク／ワイルドなら入手あり |
| オンライン | 部屋コード共有。バージョン一致必須。同じ部屋・名前で再接続。ホストはCPU化／キック可 |

## GitHub Pages

リポジトリの **Settings → Pages** で Branch を `main`（またはこのPRのブランチ）、Folder を `/ (root)` にしてください。

公開URL例: `https://makimaki510151.github.io/MkMk_Street/`

## 開発

静的ファイルのみです（ビルド不要）。ローカル確認:

```bash
python3 -m http.server 8080
```

テスト:

```bash
node --test tests/*.test.mjs
```

## 技術

- 纯フロントエンド（ES Modules）
- 描画: Canvas 2D
- 通信: [PeerJS](https://peerjs.com/)（WebRTC DataChannel、ホスト権威の状態同期）
